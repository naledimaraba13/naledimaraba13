# Credit Card Fraud Detection using Machine Learning

This project focuses on detecting fraudulent credit card transactions using machine learning techniques.

## Project Objectives
- Analyse real transaction data
- Identify patterns of fraudulent activity
- Train a machine learning model to detect fraud
- Evaluate model accuracy

## Tools & Technologies
Python
Pandas
NumPy
Scikit-learn
Data Visualization

## What I learned
Data preprocessing, data analysis, and machine learning model training.
